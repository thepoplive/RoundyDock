# RoundyDock

Rounded dock for jailbroken iOS 7-10 devices.

## Description

RoundyDock adds smooth rounded corners to your dock background, bringing a modern look to classic iOS versions.

## Features

- Rounded dock background corners
- Configurable corner radius (0-50) via Settings
- Toggle on/off
- Works on iOS 7, 8, 9, 10

## Installation

1. Add deb to Cydia
2. Install RoundyDock
3. Respring
4. Configure in Settings → RoundyDock

## Building

```bash
export THEOS=~/theos
make package FINALPACKAGE=1
```

## Compatibility

- iOS 7.0 - 10.3.4
- armv7, arm64
